Oracle Backup, Recovery & Diagnostics

Lab Overview
• Cloud: AWS
• Duration: 105 minutes
• Exercises: 3 (Full/incremental backup and whole-CDB SCN PITR, Recover a FREEPDB1 training datafile, Diagnose SQL regression and automate backup verification)
• Validations: 3
• Deployed services: AWS CloudFormation stack, Amazon VPC, public subnet, internet gateway, route table, security group, Amazon EC2 t3.large instance, encrypted EBS root volume, encrypted 30 GiB gp3 EBS backup volume, EC2 IAM role and instance profile, AWS Systems Manager
• Scenario: As the on-call DBA for an Oracle Database Free transaction-processing database on an Oracle Linux 9 EC2 instance, the learner establishes and proves an RMAN backup chain, performs whole-CDB recovery to a known SCN, and repairs a deliberately removed FREEPDB1 training datafile at PDB scope. The learner then diagnoses a seeded SQL regression, improves it with targeted optimizer statistics, and automates recurring backup verification.
